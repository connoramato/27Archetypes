3×3 System Organizer

Enter one letter in each of the 9 boxes. The tool generates all 27 three-letter keys (one letter from each row), grouped into 9 sets of 3. Values are synchronized across all three columns.

Example: A B C / D E F / G H I. Column 1 groups by the first two letters (ADG, ADH, ADI); Column 2 by the last two (ADG, BDG, CDG); Column 3 by the outside letters (ADG, AEH, AFI, etc.). Duplicate letters are allowed.
